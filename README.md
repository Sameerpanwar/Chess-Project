# Chess-Project

A real-time multiplayer chess platform built to practice full-stack development. This project demonstrates backend logic handling, real-time communication, and cloud database integration.

##  Features
- Real-time Gameplay: Move updates are synchronized across clients using WebSockets.
- User Authentication: Secure registration and login flow using MySQL.
- Cloud Persistence: Database hosted on Railway for 24/7 availability.

##  Tech Stack
- Backend: Node.js, Express
- Database: MySQL (Railway)
- Frontend: EJS, CSS, JavaScript
- Real-time: Socket.io
